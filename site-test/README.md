# WebiMade marketing-website experiment (`wod-site-test`)

A separate copy of the product used to test a marketing-website layout.
Do not deploy this as `wod` or `wod-brand-preview`. Do not edit `demo/src`
or `brand-preview/` for this experiment — source lives here in `src/`.

Build: `sh /workspace/website-on-demand/site-test/build.sh`
Deploy: from this folder, wrangler name must be `wod-site-test`.
